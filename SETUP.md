# MIDICHLORIAN.EXE GitHub README package

## Files
- README.md — the complete GitHub profile README
- assets/midichlorian-avatar.gif — animated cyberpunk scientist avatar
- assets/neural-core.gif — animated neural-core interface element

## Install
1. Create/open your GitHub profile repository.
2. Replace its README.md with this README.md.
3. Upload the entire `assets` folder alongside README.md.
4. Commit the changes.
5. If you later rename your GitHub username, update repository URLs in README.md.

## Important GitHub limitation
GitHub READMEs support animated GIFs, clickable links, and collapsible `<details>` panels, but they do not allow arbitrary JavaScript/CSS applications inside the README. The design therefore uses GitHub-compatible HTML/Markdown, animated image assets, badges, links, and collapsible interface panels rather than scripts that GitHub would strip.
