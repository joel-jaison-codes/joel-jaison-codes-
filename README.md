### GitHub Pages

1. Upload `index.html` and the `assets/` folder to a repository.
2. Commit/push them.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the main branch and `/ (root)`.
6. Save and open the generated Pages URL.

### 3D avatar

`assets/midichlorian.glb` is the supplied 10k-polygon bounty-hunter model, integrated as the MIDICHLORIAN.EXE character.

The viewer automatically rotates the model and allows manual 360° inspection. The model is loaded locally, so GitHub Pages can serve it directly from the repository.
