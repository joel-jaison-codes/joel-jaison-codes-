### GitHub Pages setup

1. Put `index.html` and the `assets/` folder in your repository.
2. Push the files to GitHub.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. GitHub will provide the Pages URL.

### About the avatar

The included avatar is animated as a holographic turntable using CSS 3D transforms. It gives a convincing cyberdeck-style 360° presentation.

For a **true volumetric 360° character**, replace it later with an actual 3D model (`.glb`/`.gltf`) and a Three.js/Babylon.js viewer. A single 2D portrait cannot contain real unseen side/back geometry.
